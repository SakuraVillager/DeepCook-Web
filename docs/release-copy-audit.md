保留工程测试、测试运行器、历史迁移中的内部标识与第三方许可。它们用于回归验证、旧数据兼容和来源追溯，不是发布界面的测试标记。AI 生成标识、服务配置条件和未保存提醒也保留，确保用户能据此判断当前状态。
